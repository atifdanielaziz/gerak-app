# Production Level Debugging Skill
💡
When investigating a live production issue or critical outage at a fast-growing startup, follow these steps:

## Investigation checklist

1. **Comprehension**: Do you fully understand what the failing code actually does?
2. **Root Cause**: Have you traced the real root cause of the failure, rather than just the symptom?
3. **Explanation**: Can you explicitly explain why the failure happens?
4. **Edge Cases**: Are there hidden edge cases that might cause further issues?

## How to provide the fix

- Break down the code functionality so the issue is easily understood.
- Provide a detailed root cause and failure explanation.
- Propose the most robust fix possible alongside fixed, production-ready code.
- Do not guess; think deeply before proposing changes.
- Analyze how edge cases are handled in your proposed fix.
