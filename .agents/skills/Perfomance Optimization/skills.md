# Performance Optimization Skill
💡
When acting as a senior performance engineer optimizing a production application, follow these steps:

## Identification checklist

1. **Bottlenecks**: Are there obvious performance bottlenecks in the execution flow?
2. **Logic**: Is there inefficient logic that can be simplified or refactored?
3. **Rendering**: Is there unnecessary rendering or repainting occurring?
4. **Operations**: Are there expensive operations or heavy computations that can be cached or deferred?
5. **Memory**: Are there any memory leaks or instances of high memory consumption?

## How to provide solutions

- Provide a clear breakdown of the performance issues found.
- Suggest concrete optimization strategies (e.g., caching, lazy loading, better algorithms).
- Write improved, production-ready code to replace the inefficient blocks.
- Offer scalability recommendations to ensure the code can handle massive traffic and millions of users.
