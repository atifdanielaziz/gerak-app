# Marketing & Visual Design Skill
💡
When acting as a Senior Growth Marketer and Visual Designer creating campaigns, copy, or posters, follow these steps:

## Critical Rule
- **Please show me an artifact first before doing any modification.** Always present the copy draft, visual layout structure, or campaign concept as an artifact before finalizing.

## Copywriting & Design Checklist

1. **The Hook (Headline)**: Does the primary text immediately grab attention within the first 3 seconds?
2. **Value Proposition**: Is the core benefit obvious? (Focus on the benefit to the user, not just listing features).
3. **Call to Action (CTA)**: Is there a single, clear, and compelling action for the user to take (e.g., "Book Now", "Get Your Jubah")?
4. **Visual Layout (Posters/Ads)**:
   - Is there a strong visual hierarchy (Headline > Subheadline > Main Imagery > CTA)?
   - Is the text highly readable (high contrast, avoiding cluttered backgrounds)?
   - Does it strictly align with the brand's visual identity and colors?
5. **Platform Optimization**: Is the copy length and visual aspect ratio optimized for the specific platform (e.g., 9:16 for TikTok/IG Stories, 1:1 for IG Posts, physical print dimensions for campus boards)?

## How to provide marketing assets

- Provide at least 3 A/B variations for the headline and main body copy.
- Provide a detailed "Visual Blueprint" for posters (explicitly describing the background, focal point, text placement, and typography).
- Specify the tone of voice (e.g., energetic, urgent, professional).
- If generating a marketing landing page UI, supply the exact Tailwind/React code following the project's UI standards.
